Excel Online / Google Sheets

Configure una o ambas conexiones. Cada registro guardado se enviará automáticamente.

Google Sheets (Apps Script)

Pegue Código.gs en Extensiones → Apps Script del Sheet, ejecute setup(), implemente como Aplicación web con acceso Cualquier usuario, y use aquí la URL /exec.

Si la prueba falla, revise que la implementación esté como Ejecutar como: Yo y Acceso: Cualquiera, y que copió la URL /exec (no la de edición del script).

Excel Online (Power Automate)

El navegador enviará el JSON completo del formato a esta URL.

Power Automate: disparador When an HTTP request is received → acción Add a row into a table en Excel Online. Por CORS, el navegador no puede confirmar la respuesta del flujo; verifique en el historial de ejecuciones de Power Automate.
